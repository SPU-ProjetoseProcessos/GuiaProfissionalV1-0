# Guia do Profissional CentralGov

Guia interativo para o servidor da SPU atender tarefas na CentralGov.

## Arquivos
- `index.html` — a página do guia.
- `imagens/` — telas do sistema e logo. Suba a pasta inteira, com este nome, ao lado do `index.html`.
- `.nojekyll` — faz o GitHub Pages servir os arquivos como estão.
